La Universidad Tecnológica del Pacífico es una universidad ficticia creada por el equipo para elaborar Tutorías UTDP, un sitio web que permite inscribirse a sesiones de tutorías, evaluar sus tutores, entre otros.
El framework utilizado para desarrollar el proyecto es Laravel. Se utilizó para crear una API para gestionar el backend de la página web.

2. Backend de los casos de uso de Evaluar y perfil.

Lo necesario para correr el proyecto:
1. Tener Laravel Instalado
2. Tener Node.js
3. Luego de instalar Laravel escribir composer install en la terminal estando en la carpeta raíz del proyecto de Laravel (Tutorias_UTDP)
4. Después escribir npm install en la terminal para las configuraciones de Vite
5. Luego decryptar el archivo de variables del proyecto (.env) o escribirme al correo para pasarles el archivo .env
6. Después escribir en una sesión de terminal npm run dev y hacer clic en el link de localhost generado
7. Antes de probar el proyecto hay que correr el servidor de Laravel con php artisan serve en la terminal
8. ¡Disfruten!
